# Code of Conduct

We pledge to make participation harassment-free for everyone. Be respectful, give specific technical feedback, disclose conflicts of interest, and protect private financial data. Harassment, threats, discriminatory language, sexualized attention, doxxing, and sustained disruption are unacceptable.

Report conduct concerns privately through the repository owner’s GitHub profile contact channel. Maintainers will preserve confidentiality where possible and may warn, restrict, or ban participants. This applies in project spaces and when representing the project publicly. Adapted from Contributor Covenant 2.1.
