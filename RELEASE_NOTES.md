# Portfolio Intelligence 0.1.0

The first public alpha includes a Python SDK, CLI, C++20/pybind11 numerical core, deterministic offline demo, provider provenance, scenario analysis, HTML reporting, and reproducible native benchmarks.

This release is intended for technical evaluation. It is not financial advice, an execution system, a tax-lot engine, or a substitute for broker statements. Performance claims are limited to measured workloads in `docs/performance.md`.

Install with `pipx install portfolio-intelligence`, `uv tool install portfolio-intelligence`, or `python -m pip install portfolio-intelligence`. Optional extras are `dashboard` and `ai`.
